# 判定模型选型

本文列出判定模型与推理强度的比较条件、结果和适用范围。

- 日期：2026-11-12
- 工具：[tools/judge_select.py](../tools/judge_select.py)。用 `python3 -m tools.judge_select setup --configs <配置名>` 准备样本，用 `python3 -m tools.judge_select compare` 比较已有判定。

## 背景

拆分判定（[框架 6.4 节](framework.md)）对每个被测系统的每段会话分别做召回判断和精确判断；每种判断按最多 30 项分批，因此调用次数取决于应记单元数和记忆条数。本文对比判定模型及推理强度。

## 方法

- **参照**：Claude Opus 5.5（推理强度 high）的判定结果，共 12 份，即 HaluMem-Medium 的 12 段会话在 OpenViking 0.5.4.1 上的输出。
- **候选**：Codex CLI 0.167.0 下的 `gpt-6.1-sol`、`gpt-6.1-terra`、`gpt-6-luna`，推理强度依次取 none、low、medium、high。`gpt-6.1-sol` 不支持 none，所以共 11 个配置。
- **指标**：每个配置重判同样的 12 份，与参照比较：
  - 召回判断：逐个应记单元比较四档结论（full / partial / none / distorted）。
  - 误记判断：逐条记忆比较“是否算误记”（无依据或写歪）。
  - 汇总指标：漏记率、误记率与参照的差距。
  - 一致率给原始一致率和 Cohen κ。

## 结果（按条误记率）

| 配置 | 召回 一致率 / κ | 误记 一致率 / κ | 漏记率（参照） | 误记率（参照） | 用时（秒） |
|---|---|---|---|---|---|
| **sol-low（选定配置）** | **92% / 0.85** | **88% / 0.64** | **40%（40%）** | **18%（24%）** | 63 |
| sol-low / medium / high | 92%–93% / 0.85–0.87 | 66%–70% / 0.31–0.37 | 40%–41%（40%） | 45%–49%（24%） | 106 / 111 / 236 |
| terra-none / low / medium / high | 80%–83% / 0.66–0.71 | 66%–76% / 0.24–0.42 | 48%–51%（40%） | 30%–41%（24%） | 180 / 90 / 93 / 181 |
| luna-none / low / medium / high | 74%–80% / 0.56–0.67 | 72%–87% / 0.41–0.63 | 49%–52%（40%） | 22%–45%（24%） | 191 / 89 / 103 / 242 |

选定的 sol-low 使用下表两项判定约定，其余配置没有同时采用这两项约定。提示词条件不同，误记差异不能仅归因于模型或推理强度。表中误记均按整条记忆比较。

## 结论

- **选用 `gpt-6.1-sol`，推理强度 low。**
- **召回判断**：sol 与参照最接近，推理强度对结果几乎没有影响。terra 和 luna 会系统性地多判漏记，比参照高 8–12 个百分点。
- **精确判断**：表中不同判定约定对应的按条误记率差异较大；采用下表约定的 sol-low 与参照的一致率为 88%，κ 为 0.64。

## 判定约定

精确判断采用以下约定：

| 约定 | 原因 |
|---|---|
| 记忆中“何时说的 / 何时记录”的日期与会话日期不符时，不作为判断依据 | 评测是事后回放会话。OpenViking 会把摄取当天的日期写进记忆正文，这个日期必然与会话日期不符，属于评测环境带来的偏差 |
| 细节缺少依据（例如名字只出自助手、用户未确认）记为部分有依据，不算写歪；写歪只指改变原意 | 不写清时，sol 和 terra 会把这类细节判为写歪，使误记率翻倍 |

## 局限

- 样本只有 HaluMem 的英文日常对话和一个被测系统；这个结论能否推广到 Trace Commons 的 coding 会话，尚未验证。
- 参照是在上述判定约定加入之前得到的，所以“是否有依据”一项的一致率普遍偏低，表中未列。
- low 和 medium 两档的召回判断有一部分命中了缓存，用时偏低，不同档位之间的用时只能粗略比较。
- 参照本身也是模型判定，最终可信度以人工抽检为准。
- 选型时误记按整条记忆比较；现行主口径按陈述计（见 [README“方法”](../README.zh-CN.md#方法)），陈述的切分与计数没有单独做选型验证，以人工抽检为准。
